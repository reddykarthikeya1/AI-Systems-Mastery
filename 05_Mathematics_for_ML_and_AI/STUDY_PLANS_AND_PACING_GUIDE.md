## Weekly shape

Whatever the track, the week that works looks like this:

| Day | Activity |
| :--- | :--- |
| 1–4 | New lessons. Predict, then run, then read the mistake section. |
| 5 | The module project. |
| 6 | The debug lab. Diagnosis written before answers. |
| 7 | Nothing. Spacing is doing work here. |

## If you fall behind

Do not skip the debug labs to catch up. Skip a module project instead — a
project can be returned to, but the diagnostic habit the labs build is the part
that transfers, and it only develops through repetition.
