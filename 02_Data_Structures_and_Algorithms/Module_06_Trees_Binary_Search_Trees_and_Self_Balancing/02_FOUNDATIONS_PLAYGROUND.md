## 1. What is a Binary Search Tree (BST)?
A tree where for EVERY node:
- Everything to the **LEFT** is **SMALLER**.
- Everything to the **RIGHT** is **BIGGER**.

```
         ( 8 )
        /     \
     ( 3 )   ( 10 )
     /   \        \
   ( 1 ) ( 6 )    ( 14 )
```
