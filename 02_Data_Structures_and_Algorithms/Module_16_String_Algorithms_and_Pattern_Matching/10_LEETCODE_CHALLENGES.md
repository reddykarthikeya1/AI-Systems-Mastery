## How the Interactive Sandbox Evaluates Your Code

1. **Dual Test Harness Execution**:
   - **Run Code**: Validates your solution against visible baseline test cases with full input/output visibility.
   - **Submit Solution**: Evaluates your algorithm against rigorous **hidden edge test cases** (boundary conditions, extreme input sizes, cyclic edge cases, and empty sets).
2. **Performance Metrics**:
   - Every submission reports execution runtime in milliseconds ($	ext{ms}$) and pass/fail distribution.
   - Solutions that exceed sandbox resource limits receive a `Time Limit Exceeded` (TLE) error.
3. **Reference Solution & Explanations**:
   - Once all test cases pass with $100\%$ accuracy, the interactive studio unlocks the **Official Production Solution** and algorithmic breakdown.
