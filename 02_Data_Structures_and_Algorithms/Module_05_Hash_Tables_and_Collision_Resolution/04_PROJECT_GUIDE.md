# Project Guide: Building Hash Tables & Collision Resolution

## Objective
Implement a production-grade, memory-efficient, robust Hash Tables & Collision Resolution engine in Python with full type annotations, zero external dependencies, and exhaustive boundary validation.

## Requirements & Acceptance Criteria
1. **Correctness**: Maintain all invariants across arbitrary sequences of insertions, updates, and deletions.
2. **Complexity Guarantees**: Adhere strictly to the required theoretical Big-O time and space bounds.
3. **Safety**: Raise appropriate typed exceptions for invalid operations (e.g. empty queue pop, index out of range).

## Directory Layout
- `starter/`: Fill in the skeleton methods.
- `project_solution/`: Reference implementation with automated test suite.
- `debug_lab/`: Deliberately broken scenarios for diagnosis.
