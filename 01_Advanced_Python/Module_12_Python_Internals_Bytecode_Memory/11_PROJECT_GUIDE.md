## Tier 2 — Core Project: Complete Turnkey Implementation

### Step 3 — Slotted Models
Implement `SlottedUser` using `__slots__ = ("name", "uid")` and demonstrate the absence of an instance `__dict__`.

### Step 4 — AST Security Auditing
Implement `audit_ast_security(source_code)` traversing AST nodes to detect banned builtins (`eval`, `exec`) and mutable default arguments.

### 💥 Deliberately Break It (Do this — it is the lesson!)
In `starter/internals_profiler.py`, comment out `__slots__ = ("name", "uid")` in `SlottedUser`.
Run:
```bash
pytest ../project_solution/test_internals_profiler.py -k test_regular_user_has_dict_slotted_does_not -v
```
Watch the test fail because the instance has a `__dict__`, then restore `__slots__` and watch it pass.

### ✅ Tier 2 Acceptance
Run the full test suite:

```bash
pytest ../project_solution/test_internals_profiler.py -v
```
All tests must pass cleanly.

## Tier 3 — Architect Stretch: Advanced Production Challenges

1. **Recursive Deep Object Sizer:** Build a deep `sys.getsizeof` walker visiting all referenced sub-objects.
2. **Bytecode Peephole Optimizer Tracker:** Compare generated bytecode between unoptimized and constant-folded expressions.
3. **Reference Cycle Detector:** Use `gc.get_referents()` and `gc.get_referrers()` to trace circular references.
4. **PyObject Structure Viewer:** Use `ctypes` to read `ob_refcnt` and `ob_type` pointers from memory addresses.
