# Project Guide: Building Continuous & Dynamic Batching (Orca)

## Overview
Implement a production-grade, battle-tested reference implementation of **Continuous & Dynamic Batching (Orca)**.

## Architectural Requirements
1. **Correctness & Invariants**: Maintain zero data corruption, race conditions, or memory leaks.
2. **Performance Constraints**: Optimize memory access patterns and minimize overhead.
3. **Observability & Testing**: Provide clear metrics, logging, and comprehensive unit tests.

## Workspaces
- `starter/`: Starter boilerplate with docstrings and type signatures.
- `project_solution/`: Completed reference implementation.
- `debug_lab/`: Planted bugs and failure symptoms for practice.
