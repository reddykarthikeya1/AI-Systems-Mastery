## How this course is built

Each module carries the same structure, and the structure is a set of promises:

| Artifact | The promise it makes |
| :--- | :--- |
| `lessons/` | One file per lesson. Each has objectives, a fully worked example, runnable code that **asserts**, and a named common mistake. |
| `project_solution/` | A reference implementation with tests. The tests are the specification. |
| `starter/` | Stubs. Running the shipped tests from here must **fail** — see below. |
| `debug_lab/` | Planted defects that produce *plausible wrong answers*, not crashes. |
| `PROJECT_GUIDE.md` | A 3-tier build path where Tier 1 is a coherent stopping point. |
| `SELF_ASSESSMENT_AND_CHALLENGES.md` | Quiz, challenges, and diagnostics weighted above the quiz. |
| `TROUBLESHOOTING_AND_EDGE_CASES.md` | Failure modes actually hit while building, not invented in advance. |

### The grading loop

`starter/conftest.py` redirects imports to the learner's own code. Running a
module's shipped tests from `starter/` must produce **failures**, every one a
`NotImplementedError`:

```bash
cd Module_01_*/starter
python -m pytest ../project_solution -q     # must FAIL
```

If a test passes on an untouched starter, the loop is broken and is certifying
work that was never done. That is the single worst failure a course can have,
and it is checked rather than assumed.

### Verification

```bash
python -m pytest -q                 # all module tests
python tools/check_links.py         # no broken links, no absolute paths
python tools/check_deps.py          # every third-party import declared
ruff check .                        # lint
```
